# @saas-builder/extensibility-contract

Stack-agnostic types and JSON schemas for the 3-layer extensibility model:

- **L1** `StaticConfig` — brand, flags, SEO
- **L2** `DynamicConfig` — navigation, actions, slots
- **L3** `EndpointMap` — reroute rules and hook names

Use with `@saas-builder/extensibility-vue` (frontends) and `backend-extensibility-lib` (Spring).
